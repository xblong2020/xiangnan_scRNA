# Code Availability

The analysis code is publicly available at https://github.com/xblong2020/xiangnan_scRNA, GitHub Release v1.0.0. The release tag points to the audited frozen commit 1c0303049ba629b9b986cb9a7e088384f15f5a87. A Zenodo permanent archival identifier remains pending.

The final manuscript wording includes the verified GitHub Release and must be updated again only after the Zenodo archive response has been independently verified. The code release excludes restricted raw human data, patient-level sensitive files, large sequencing files, local environments, caches, credentials, and unapproved derived outputs. Accession-based retrieval instructions and source-data provenance records are retained where permitted.

The exact historical software version for every analysis step is not fully recoverable; historical_exact_version_not_recoverable remains an explicit limitation. This local closure performed repository and documentation work only and did not rerun biological analyses.
